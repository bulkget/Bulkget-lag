# VocabRoom Explorer — 3D Room Map

A mobile-first React + Vite vocabulary map. This is not a game: choose a category, explore its 3D-styled room, and tap any object to view its English word, Thai meaning, pronunciation guide, and example sentence.

## Included
- 5 categorized scenes: Bedroom, Kitchen, Living Room, Bathroom, Garden
- 30 clickable vocabulary objects in every scene (150 total)
- Tap objects on the map or select words from the list
- English audio pronunciation via the browser's Web Speech API
- Drag to pan, pinch to zoom on touch devices, mouse-wheel zoom, zoom controls, reset
- Responsive portrait and landscape layouts
- Search within each room

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
