# VocabRoom Explorer — Mobile React

เว็บแอปเรียนคำศัพท์ภาษาอังกฤษจากภาพอ้างอิงแบบ mobile-first

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## จุดที่ทำไว้
- Dashboard / แผนที่บ้าน
- ห้อง Bedroom / Kitchen / Living Room
- คลังคำศัพท์แบบค้นหาได้
- Modal รายละเอียดคำศัพท์
- Web Speech API สำหรับออกเสียงภาษาอังกฤษ
- ระบบดาว + progress
- Daily mission
- Quiz แบบง่าย
- Responsive สำหรับมือถือ
- ใช้ React + Vite + lucide-react
